# DESIGN.md — Omar Torbi Portfolio & Maro Technical Copilot

## Identity & Voice
- **Subject**: Omar Torbi — Software & DevOps Engineer | EMSI Final Year Student (DDSI).
- **Agent**: Maro — Technical Copilot & Engineering Assistant.
- **Voice**: Precise, factual, engineering-first, articulate, zero fluff. No corporate clichés, no fake marketing hype, no ungrounded claims.

## Visual Language
- **Theme**: Monochromatic Precision Dark/Light System.
  - Light mode: Crisp zinc/slate backgrounds (`#fafafa` / `#ffffff`), deep charcoal typography (`#09090b`), subtle neutral borders (`#e4e4e7`).
  - Dark mode: Obsidian background (`#09090b` / `#0d0d11`), high-legibility light text (`#f4f4f5`), refined dark borders (`rgba(255,255,255,0.08)`).
- **Accent**: One deliberate accent: Electric Cyan (`#06b6d4` / `#0891b2`) reserved strictly for key interactive elements, code highlight tokens, and focus rings.
- **Typography**:
  - Primary UI & Prose: High-contrast grotesque sans-serif with tight negative tracking on headings (`tracking-tight`) and generous line heights for body text (`leading-relaxed`).
  - Monospace: Technical code, metrics, and parameters (`font-mono`). No fake terminal costumes.

## Liveliness Dials
- **ENERGY**: 2 (Balanced — technical clarity with deliberate emphasis).
- **RHYTHM**: 2 (Structured — clear hierarchy between dialogue, code blocks, and action recommendations).
- **MOTION**: 2 (Purposeful transitions — enter/exit spring, token streaming cursor, focus feedback. Zero endless looping pulses).

## Anti-Slop Commitments
- No decorative emojis in UI elements or headings.
- No fake traffic-light terminal dots on code snippets; clean functional code blocks with language badge and copy action.
- No generic "AI Powered" badges or pulsing "ONLINE // AUTONOMOUS" status beacons.
- All metrics and credentials are 100% verified (OCI DevOps Professional, OCI Architect Professional, Java SE 17).
- Real working actions only: verified PDF resume downloads, direct email links, GitHub repositories, and section navigation.
- Full keyboard navigation (Esc to dismiss, Tab indexing, visible focus rings) and WCAG AA contrast compliance across dark and light modes.
