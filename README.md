## 🖥️ System Architecture & Features

### 1. Essential Portfolio Applications
- **About Omar (`win-about`):** Engineering profile, state engineering degree at EMSI Rabat (DDSI), dual Oracle Cloud (OCI) professional certifications, and recruiter quick-actions.
- **Projects Explorer (`win-projects`):** Classic Finder-style 2-column technical inspector detailing 6 production deployments (Elevate, Zahiri Metal 3D CAD, Scraping Automations, Microservices Architectures) with architectural highlights, bottleneck resolutions, and live links.
- **System Profiler: Capabilities (`win-capabilities`):** Deep dive into technical subsystems (Backend Systems, Cloud & DevOps, Frontend Engineering, Data Architecture) with visual proficiency meters and verified production contexts.
- **Event Journal: Experience (`win-experience`):** Chronological audit trail of professional history, deliverables, and engineering milestones.
- **MacMail Dispatcher (`win-contact`):** Instant recruiter mailer with pre-filled End-of-Studies (PFE) Internship and Full-Time role templates, direct WhatsApp channel, and verified English / French CV downloads.

### 2. Retro Accessories & Extras
- **Phosphor CRT Terminal (`win-terminal`):** Interactive VT100 phosphor green command-line shell with custom commands (`help`, `neofetch`, `skills`, `projects`, `certs`, `cat resume`, `sudo`).
- **MacPaint 1.0 (`win-paint`):** 1-bit monochrome canvas drawing studio with pencils, brushes, erasers, and PNG artwork export.
- **Walkman-84 Tape Deck (`win-walkman`):** Dual mechanical spools with an 8-bit Web Audio API chiptune synthesizer and cassette track selector.
- **Control Panels & Themes (`win-settings`):** Customizable retro wallpaper schemes (Vaporwave Sunset, Windows 95 Teal, Candy Pastel Pop, iMac Bondi Blue, Cyber Matrix, Classic Platinum) and raster electron-beam CRT scanline overlay.
- **Trash Can (`win-trash`):** System cleanup utility for legacy anti-patterns and unindexed slow queries.

### 3. Audio & Visual Authenticity
- **Synthesized Web Audio Effects:** Macintosh startup chime, floppy drive seek/read motor, Sosumi warning beep, window collapse/drag sounds, and tactile mechanical clicks.
- **Pinstripe Windows:** True mathematical center plaques, vintage close boxes, windowshade roll-up buttons, and draggable/resizable window frames.

## 🛠️ Tech Stack

- **Framework:** React 18 (Hooks, Context, Web Audio API)
- **Language:** TypeScript 5.7
- **Styling:** Tailwind CSS 3.4 with custom vintage typography (`VT323`, `Silkscreen`, `Press Start 2P`, `JetBrains Mono`)
- **Icons:** Custom 1-bit SVG pixel icons + Lucide React
- **Build Tool:** Vite 6.1
- **Deployment:** Vercel Production (`omartorbi.engineer`)

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TORBIomar/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
